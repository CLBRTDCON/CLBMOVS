# Cinema LB TV

Descargas de Cinema LB para Android TV / Google TV (Android 8 o posterior).

La APK se distribuye en [Releases](https://github.com/CLBRTDCON/CLBMOVS/releases).

## Instalación

Descarga `CLB-TV.apk` desde la última publicación y ábrela con Downloader o el instalador de Android TV. Instala sobre la versión anterior para conservar los datos.

## Créditos

AVPlayer / libmedia 1.3.1 (LGPLv3); licencia incluida en la APK y accesible desde los créditos de la aplicación. HLS.js 1.7.3 (Apache-2.0).

Este repositorio distribuye la aplicación; no aloja archivos de películas o series.
